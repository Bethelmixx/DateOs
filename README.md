# DateOs

Mapa de reportes comunitarios para Venezuela (cortes de luz, agua, tráfico y más).

## Descargar ZIP

https://github.com/Bethelmixx/DateOs/archive/refs/heads/main.zip

## Correr en una computadora

```bash
npm install
npm run dev
```

Esto es el código fuente, no un APK. Para Android nativo hay que envolverlo después con Capacitor.
